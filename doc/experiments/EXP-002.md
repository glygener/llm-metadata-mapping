# Change Category

Few-shot Example Addition

# Intent

Improve recognition of valid rare disease terms that the baseline prompt incorrectly classifies as unidentifiable.

# Expected Outcome

Correctly identify Kanzaki disease and resolve it to its corresponding Disease Ontology identifier without introducing incorrect mappings or changing unrelated disease predictions.

# Benchmark Dataset

A 30-term benchmark consisting of Kanzaki disease and 29 randomly selected terms from the remaining 92 disease terms in the dataset. Random selection used seed 20261112.

Baseline results came from `diseases/data/mapping_BS_Disease_LLM_OLS_results.xlsx`. Experimental results came from one GPT-4o run using temperature 0, saved at `/tmp/EXP-002_modified_results.csv`. Both runs used the same 30 terms.

The modified prompt added a few-shot example instructing the model to recognize Kanzaki disease as a valid disease term and preserve its name. No other prompt instructions were changed.

Since LLM output can vary between runs, these results describe one observed run and do not prove that the prompt change alone caused every difference.

## Interpretation

The baseline prompt returned `No Match Found` for Kanzaki disease. The modified prompt returned `Kanzaki disease`, which successfully resolved to `DOID:0112319`, matching the curated identifier.

Kanzaki disease was the only term whose scientific name changed. The other 29 terms retained their baseline scientific names and correct ontology mappings.

Across all 30 terms, Coverage, Ontology Coverage, and Correct Mapping Rate each increased from 96.67% to 100.00%. Dangerous Error Rate remained at 0.00%, and there were no Resolution Regressions.

The generalization subset was already at 100.00% for Coverage, Ontology Coverage, and Correct Mapping Rate before the change and remained unchanged afterward. Therefore, this experiment demonstrates a successful targeted correction but does not establish broader improvements in rare-disease recognition.

Preferred Label Usage was calculated by comparing the proposed scientific name with the selected OLS label using case-insensitive exact string equality.

# Decision

ACCEPT

# Reason

The modification corrected the targeted Kanzaki disease failure, producing one Additional Correct Resolution without introducing any Resolution Regressions or increasing Dangerous Error Rate. The change was isolated to the intended example, with all other benchmark predictions remaining unchanged.

Acceptance is limited to this targeted correction; broader generalization has not been demonstrated.

# Follow-up Idea

Test the same approach with additional independently selected rare disease terms that have verified ontology identifiers but were previously classified as `No Match Found`. Evaluate them separately from terms explicitly included as prompt examples.
