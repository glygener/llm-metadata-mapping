# Change Category

Constraint Addition

# Intent

Reduce incorrect ontology assignments caused by treating an anatomically related structure or subtype as equivalent to the input term.

# Expected Outcome

Decrease Dangerous Error Rate and Resolution Regressions by explicitly requiring anatomical equivalence rather than association alone.

# Benchmark Dataset

Curated tissue-mapping benchmark containing 224 unique tissue terms. Baseline results came from `tissues/data/mapping_BS_Tissue-mapped_processed.xlsx`. Experiment results came from one GPT-4o benchmark run saved at `/tmp/tissue_experiment_b8e34b8.xlsx`. Both runs used the same 224 terms. Since LLM output can vary between runs, these results describe one observed run and do not prove that the prompt change alone caused every difference.

# Results

## Before

- Coverage: 78.12%
- No Scientific Term: 21.88%
- Ontology Coverage: 75.89%
- Unresolvable Scientific Term: 2.23%
- Correct Mapping Rate: 69.64%
- Dangerous Error Rate: 8.24%
- Preferred Label Usage: 75.88%
- Correct mappings: 156
- UBERON-resolvable terms: 170

## After

- Coverage: 80.36%
- No Scientific Term: 19.64%
- Ontology Coverage: 77.68%
- Unresolvable Scientific Term: 2.68%
- Correct Mapping Rate: 70.98%
- Dangerous Error Rate: 8.62%
- Preferred Label Usage: 76.44%
- Correct mappings: 159
- UBERON-resolvable terms: 174

- Additional Correct Resolutions: 18
- Resolution Regressions: 15

## Interpretation

Coverage increased by 2.23 percentage points, ontology coverage increased by 1.79 points, and correct mapping rate increased by 1.34 points. There were 18 additional correct resolutions, but also 15 resolution regressions. Dangerous Error Rate increased by 0.39 percentage points, from 8.24% to 8.62%, and Unresolvable Scientific Term increased by 0.45 points.

The change did not meet the project's higher-priority goals of reducing dangerous errors and avoiding regressions. Because this was one run of a potentially variable LLM, the results should be treated as observed benchmark evidence rather than proof of causation.

# Decision

REJECT

# Reason

Dangerous Error Rate increased and the experiment introduced 15 Resolution Regressions. Under the project's priority order, these outweigh the improvements in coverage and the 18 additional correct resolutions.

# Follow-up Idea

Test a narrower prompt change with examples distinguishing closely related anatomical concepts, then benchmark it against the restored baseline using the same curated term set.
