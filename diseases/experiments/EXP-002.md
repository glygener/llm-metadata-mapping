EXP-002

# Volunteer
Luis Jimenez

# Change Category
Dataset validation

# Intent
Run the existing disease mapping pipeline on the 42 unmapped disease terms assigned to rows 90–131 of the shared review sheet.

# Method
The same script and prompt used in the baseline experiment were applied. No prompt changes were made. ChatGPT suggestions, OLS names, and OLS identifiers were manually reviewed.

# Results
- 42 rows were processed.
- 29 rows had a reference DOID.
- 21 of 29 reference DOIDs matched the OLS result (72.4%).
- ChatGPT returned “No Match Found” for 11 rows.
- OLS returned a name and identifier for 26 rows.
- Manual review accepted 39 of 42 ChatGPT results.
- Manual review accepted 34 of 42 OLS results or appropriate no-match responses.

# Main Findings
- The broad term “tumor” was incorrectly mapped by OLS to “dermis tumor”.
- “Tn polyagglutination syndrome” was missed even though it has a valid Disease Ontology term.
- “Gastric polyps” was mapped to the overly specific “Peutz-Jeghers syndrome”.
- Some correct ChatGPT normalizations did not produce an OLS result, including sialidosis type II, HSV-1 infection, gestational trophoblastic disease, and invasive hydatidiform mole.
- Several inputs described viruses, proteins, experimental models, or normal samples rather than diseases, so “No Match Found” was appropriate.

# Decision
VALIDATION

# Reason
This run evaluates the current baseline pipeline on the assigned unmapped disease terms. It does not test a new prompt.

# Follow-up Idea
Improve the OLS search fallback and prevent the selection of overly specific diseases when the original input is broad.
