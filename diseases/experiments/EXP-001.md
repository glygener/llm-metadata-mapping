# Intent
Evaluate the original disease normalization prompt before making any prompt modifications.

# Expected Outcome
Establish baseline coverage, mapping accuracy, preferred label usage, and dangerous error rate on the disease benchmark dataset.

# Benchmark Dataset
mapping_Disease-mapped.xlsx: 23 rows representing 22 unique disease terms.

# Results Before
Not applicable. This is the baseline experiment.

# Results After
- Coverage: 100.0% (23/23 rows produced an LLM term and an OLS result).
- Raw automatic ID match rate: 91.3% (21/23).
- Manually corrected ID match rate: 95.7% (22/23), after recognizing that DOID_8536 and DOID:8536 represent the same identifier.
- Preferred label usage: 78.3% (18/23).
- Dangerous error rate: 4.3% (1/23).
- Four unique input terms were correctly normalized to preferred disease names.
- One duplicate Shingles row and one inconsistent DOID separator were identified in the benchmark data.

# Interpretation
The baseline successfully mapped most disease terms and correctly normalized hepatoma, aspartylglycosaminuria, myeloma, and Shingles. The apparent Shingles mismatch was caused by inconsistent identifier formatting rather than an incorrect mapping. The only true dangerous mapping was mannosidosis, which was mapped to beta-mannosidosis even though the input did not specify a subtype. An end-to-end regeneration was attempted after implementing the DOID identifier normalization fix, but the OpenAI API returned HTTP 400 before the first batch completed. The existing baseline result files were not overwritten.

# Decision
BASELINE

# Reason
This experiment establishes the reference performance for future prompt changes. No prompt modification was evaluated in this experiment.

# Follow-up Idea
Normalize DOID separators in the comparison script and test a prompt rule that prevents the model from selecting a specific disease subtype when the input is ambiguous.
