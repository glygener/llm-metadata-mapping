# Results After
- The full baseline run completed successfully for both benchmark files.
- Total evaluated: 116 rows representing 94 unique disease terms.
- mapping_Disease-mapped.xlsx: 22/23 matching IDs (95.7%).
- mapping_BS_Disease-mapped.xlsx: 91/93 matching IDs (97.8%).

- One identifier formatting difference (DOID_8536 versus DOID:8536) was correctly normalized.
- Two unique terms require manual review: mannosidosis and Kanzaki disease.

# Interpretation
The baseline pipeline completed successfully using ChatGPT and OLS. Mannosidosis appeared in both datasets. The input term is ambiguous, while the pipeline returned the more specific beta-mannosidosis (DOID:3633), so this result should not be accepted automatically. For Kanzaki disease, ChatGPT returned No Match Found even though Kanzaki disease and DOID:0112319 are valid in Disease Ontology. This is a false negative. These results show that the pipeline performs well overall but needs better handling of ambiguous terms and exact valid disease names.
