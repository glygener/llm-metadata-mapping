# llm-metadata-mapping
Mapping database metadata (publication, species, tissue, disease) to established ontologies and dictionaries using LLM
In the data folder, only the most recent data is excluded from the old data folder.
In the script folder, only the most recent script and prompt used to generate the most recent data is excluded from the old_scripts folder.
The csv_rw folder present in the script folder, consists of some scripts I used to read and write CSV files.
